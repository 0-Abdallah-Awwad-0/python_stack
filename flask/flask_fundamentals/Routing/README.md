\# Understanding Routing Assignment



This assignment practices routing in Flask.



\## Main Idea



Flask routes connect URLs to Python functions.



Different URLs return different responses.



\## Routes



\### Root Route

URL:

/



Response:

Hello World!



\### Champion Route

URL:

/Champion



Response:

Champion!



\### Dynamic Route

URL:

/say/name



Example:

/say/Flask



Response:

Hi Flask!



\### Repeat Route

URL:

/repeat/number/word



Example:

/repeat/5/hello



Response:

hello repeated 5 times



\## Error Handling



Invalid routes display:

Sorry! No response. Try again.

\- Routes

\- Route variables

\- Error handling
