\# Zoo Assignment



This assignment practices inheritance, associations, polymorphism, and method overriding.



\## Main Idea



A Zoo object manages multiple Animal objects.



Different animals inherit from the Animal class and behave differently.



\## Classes



\### Animal

Parent class containing:

\- name

\- age

\- health

\- happiness



Methods:

\- feed()

\- display\_info()



\### Lion, Monkey, Bear

Child classes inheriting from Animal.



Each animal:

\- has unique attributes

\- overrides methods differently



\### Zoo

Stores all animals inside a list and manages them.



\## OOP Concepts



\### Inheritance

Lion, Monkey, and Bear inherit from Animal.



\### Polymorphism

Each animal uses feed() differently.



\### Overriding

Child classes override parent methods.



\### Association

Zoo HAS Animal objects.



\## Purpose



This assignment practices:

\- Inheritance

\- Polymorphism

\- Overriding

\- Associations

\- Working with objects
