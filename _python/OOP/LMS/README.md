\# Library Management System



This assignment practices advanced Object-Oriented Programming concepts.



\## Main Idea



The system manages different library items:

\- Books

\- Magazines

\- DVDs



All items can:

\- be borrowed

\- be returned

\- check availability

\- notify overdue users



\## OOP Concepts



\### Inheritance

Book, Magazine, and DVD inherit from LibraryItem.



\### Encapsulation

Borrower information and due dates are protected inside the class.



\### Polymorphism

Each item calculates late fees differently using the same method name.



\### Abstraction

LibraryItem acts as the common structure for all library items.



\## Purpose



This assignment practices:

\- Inheritance

\- Encapsulation

\- Polymorphism

\- Abstraction

\- Real-world OOP design
