# Bank Account Assignment

This assignment practices Object-Oriented Programming in Python by creating a BankAccount class.

## Features
- Deposit money
- Withdraw money
- Apply interest
- Display balance
- Method chaining

## Methods

### deposit(amount)
Adds money to the balance.

### withdraw(amount)
Withdraws money from the balance.

If there are insufficient funds, the account is charged a $5 fee.

### yield_interest()
Adds interest to the balance if the balance is positive.

### display_account_info()
Displays the current balance.

## Method Chaining

The methods return self, allowing multiple methods to be chained together.
